# Session 01 — PROJECT BLUEPRINT

You are the lead product architect for a new website called a Local Business Growth Platform.

Goal: help Indian small/local businesses improve their Google visibility, Google Business Profile, local SEO, reviews, website presence, and customer acquisition.

Create the project's master architecture and product roadmap. Define:
- target users and problems
- USP and positioning
- free vs Pro features
- core user journey: Learn → Check → Fix → Monitor → Automate
- technical direction suitable for a lightweight modern web app
- SEO/content architecture
- future Google Business Profile/API integration
- AI audit and AI review-management architecture
- trust, privacy and Google-policy considerations

Do NOT build the website yet. Do NOT create future modules. Only document the architecture.

Create/update PROJECT-ROADMAP.md and nothing else.
At the end, summarize exactly what was documented and stop.

## SESSION CONTROL
- Do ONLY this session's task.
- Do NOT start future roadmap modules.
- Inspect the existing project before changing files.
- Preserve working functionality.
- Do not invent APIs, credentials, rankings, data, reviews, or business facts.
- Never expose secrets or API keys.
