सिस्टम स्थिति

जब API इस वेबसाइट से जुड़ा होता है, यह पेज LocalBoost API पर असली हेल्थ चेक चलाता है। जुड़ा न हो तो यही कहता है। यह कोई अपटाइम प्रतिशत नहीं दिखाता और ऐसी मॉनिटरिंग का दावा नहीं करता जो हम चलाते नहीं।

आखिरी अपडेट 30 अक्टूबर 2026

जाँच हो रही है...

यह जाँच क्या करती है

API जुड़ा हो तो आपका ब्राउज़र API के /health पते पर एक अनुरोध भेजता है और जो लौटा वह ज्यों का त्यों दिखाता है: HTTP स्थिति, सेवा का नाम, डेटाबेस जाँच पास हुई या नहीं, आपके डिवाइस से राउंड-ट्रिप में कितना समय लगा और जाँच का समय। नतीजा इसी पल और इसी ब्राउज़र के लिए है। यह अतीत का रिकॉर्ड नहीं है।

यह पेज क्या नहीं करता

  • यह अपटाइम प्रतिशत या घटनाओं का इतिहास नहीं दिखाता, क्योंकि हम अभी लगातार मॉनिटरिंग नहीं चलाते और वह इतिहास नहीं रखते।
  • यह Google, Razorpay या किसी और प्रदाता को नहीं जाँचता। उनमें से किसी में गड़बड़ हो तो यह पेज नहीं जान पाएगा।
  • यह साबित नहीं करता कि हर फ़ीचर चल रहा है। हेल्थ चेक बस पुष्टि करता है कि API ने जवाब दिया और एक मामूली डेटाबेस क्वेरी चला सका। अलग-अलग फ़ीचर फिर भी विफल हो सकते हैं।

आज के घटक

घटकआज की स्थिति
------
स्टैटिक वेबसाइट (पेज, फ्री टूल)आप यह पेज पढ़ रहे हैं, यानी खोलते समय यह पहुँच में था। हम इसे लगातार मॉनिटर नहीं करते
LocalBoost API (Cloudflare Worker)ऊपर दिखाया गया है। प्रोडक्शन डिप्लॉयमेंट जाँचे जाने तक API इस वेबसाइट से जुड़ा नहीं है
डेटाबेसजुड़ा होने पर केवल API हेल्थ चेक द्वारा बताया जाता है
Google साइन-इन और Business Profile पहुँचलाइव नहीं। Google की मंज़ूरी का इंतज़ार
पेमेंट (Razorpay)लाइव नहीं। पेमेंट अकाउंट की मंज़ूरी का इंतज़ार
रैंक डेटा प्रोवाइडरजुड़ा नहीं। कोई वेंडर चुना नहीं गया
ईमेल भेजनाकॉन्फ़िगर नहीं

अगर कुछ गड़बड़ लगे

यह पेज देखें, फिर हेल्प सेंटर और समस्या निवारण गाइड। समस्या बनी रहे तो पेज का पता, समय और जो दिखा वह लिखकर बग रिपोर्ट भेजें या support@localboost.in पर ईमेल करें। अगर त्रुटि संदेश में अनुरोध की पहचान दिखे तो वह भी लिखें।

जाँच कैसे बनाई गई है

अनुरोध कोई कुकी इस्तेमाल नहीं करता और कोई व्यक्तिगत डेटा नहीं भेजता। यह ब्राउज़र से कैश्ड जवाब न इस्तेमाल करने को कहता है, आठ सेकंड बाद हार मान लेता है और पढ़े जा सकने वाले सफल जवाब के सिवा किसी भी चीज़ को अंदाज़ा लगाने की जगह विफल जाँच मानता है। अगर कोई ब्राउज़र एक्सटेंशन, फ़ायरवॉल या क्रॉस-ओरिजिन सेटिंग अनुरोध रोके, तो आपको "पहुँच नहीं हो सकी" दिखेगा, और यह पेज उन कारणों को असली आउटेज से अलग नहीं कर सकता।

आगे की योजना

प्रोडक्शन API चलने के बाद हम स्वतंत्र मॉनिटरिंग और प्रकाशित घटना इतिहास जोड़ना चाहते हैं। जब तक वह नहीं है, हम उसका वर्णन नहीं करेंगे। जब होगी, चेंजलॉग में लिखा जाएगा।
