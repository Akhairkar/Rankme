# Session 03 — DESIGN SYSTEM

Create the design system for the Local Business Growth Platform.

The design must be modern, trustworthy, mobile-first, fast and professional. Avoid an overly dark or overly white appearance.

Define:
- brand direction
- color tokens
- typography
- spacing
- buttons
- cards
- forms
- alerts
- score/progress components
- navigation
- footer
- responsive breakpoints
- accessibility requirements
- image/illustration style

Prefer original UI illustrations/mockups over generic stock photos.

Do not redesign or code the homepage yet.

Create/update DESIGN-SYSTEM.md only.
